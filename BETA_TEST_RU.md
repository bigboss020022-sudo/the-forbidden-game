# Бета-просмотр новых карт

Локальный просмотр запускается командой:

```powershell
node scripts/preview.cjs
```

Откройте `http://127.0.0.1:4173/?betaTest=1`. Страница сразу покажет колоду со всеми восемью присланными иллюстрациями. На главном экране нажмите «Все карты», чтобы открыть каталог; нажатие на карту показывает изображение, описание и визуальный эффект. При «Получить карту» сначала появляется экран обработки, затем карта.

Адрес `127.0.0.1` работает только на этом компьютере. Он не откроется на телефоне или в Telegram на телефоне; для этого нужен доступный телефону HTTPS-адрес.

Параметр `betaTest=1` включает только локальную тестовую выдачу. В этом режиме приложение не запрашивает Telegram API и не меняет серверную коллекцию. Без параметра новые карты не добавляются в начальные карты браузерного режима; в Telegram они выдаются сервером по редким весам и лимитам.

Для завершения теста достаточно убрать параметр из адреса. При удалении временной бета-выдачи сохраняются иллюстрации карт, их оформление и серверные шансы выпадения.
