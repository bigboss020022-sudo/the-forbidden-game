# The Forbidden API — прототип серверной выдачи карт

Этот каталог — отдельный API-прототип для следующего этапа. Его **нельзя просто загрузить в GitHub Pages**: Pages размещает статические файлы и не запускает Python.

## Что реализовано
- SQLite-хранилище экземпляров карт с уникальным serial ID.
- Проверка подписи Telegram Mini App `initData` на сервере.
- `POST /api/draw`: случайная выдача по весам; лимитированные карты исключаются из пула после достижения `max_copies`.
- `BEGIN IMMEDIATE` в SQLite, чтобы параллельные запросы не превысили общий лимит.
- `GET /api/me/cards` и перенос конкретного экземпляра между `deck` и `taboo`.

## Локальный запуск для разработчика
1. Установить Python 3.11+.
2. `py -m pip install -r requirements.txt`
3. Установить `BOT_TOKEN` в переменные окружения локально; не публиковать его.
4. `py -m uvicorn app:app --reload --port 8000`
5. Проверить `http://127.0.0.1:8000/health`.

## Важно перед реальным запуском
- В `CARD_DEFS` сейчас демонстрационные веса, а «Мечта» имеет примерный лимит 10. Это не утверждённые игровые балансы: уточнить шансы и лимиты перед production.
- API пока не подключён к `webapp/app.js` и не размещён в интернете. До подключения кнопка «Получить карту» в браузере остаётся демонстрационной и не обеспечивает глобальные лимиты.
- Для настоящего многопользовательского режима нужен HTTPS-хостинг API с постоянным диском/базой данных и секретом `BOT_TOKEN` в настройках хостинга.
- SQLite подходит для небольшого раннего прототипа. Перед большим релизом лучше использовать PostgreSQL и резервные копии.
