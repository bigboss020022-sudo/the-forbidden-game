# The Forbidden API

FastAPI API игры с хранением экземпляров карт в PostgreSQL. GitHub Pages запускает только интерфейс; Python API работает отдельно на Render.

## Запуск

Требуются Python 3.11+, PostgreSQL и переменные окружения:

- `DATABASE_URL` — адрес PostgreSQL;
- `BOT_TOKEN` — токен Telegram-бота; хранить только в переменных окружения хостинга;
- `APP_ORIGIN` — точный HTTPS-origin сайта с мини-приложением. По умолчанию задан старый адрес `https://bigboss020022-sudo.github.io`; при переносе сайта на другой аккаунт значение нужно обновить в Render.

```powershell
py -m pip install -r requirements.txt
$env:APP_ORIGIN = "https://example.github.io"
py -m uvicorn app:app --reload --port 8000
```

На Render используется каталог `server`, команда установки `pip install -r requirements.txt` и запуск `uvicorn app:app --host 0.0.0.0 --port $PORT`.

## API

- `GET /health` — состояние процесса и наличие обязательных настроек; значения секретов не возвращаются.
- `GET /api/catalog` — определения карт и агрегаты по числу копий и владельцев. Идентификаторы игроков не раскрываются. Сводка кэшируется на минуту и сбрасывается после выдачи, крафта и первой стартовой выдачи в процессе.
- `GET /api/me/cards` — коллекция игрока; требует подписанные Telegram Mini App `initData`.
- `POST /api/draw` — выдача карты по весам с проверкой общего лимита.
- `POST /api/craft` — атомарный крафт по одному из известных рецептов.
- `POST /api/me/card-zone` — перемещение собственного экземпляра между `deck` и `taboo`.

Таблицы PostgreSQL создаются и обновляются идемпотентно при запуске. Не удаляйте таблицы и не выполняйте сброс базы: в них хранятся коллекции игроков.

## Проверки перед публикацией

Локально проверьте `GET /health`, работу API с Telegram `initData` и соединение с тестовой PostgreSQL. Не используйте production-базу для ручных тестовых выдач или крафта. На GitHub Pages и Render публикуйте изменения отдельно; Render должен быть подключён к основной ветке и запускать каталог `server`.

Веса и лимиты в `CARD_DEFS` остаются игровыми настройками проекта. Перед изменением экономики согласуйте значения отдельно.
